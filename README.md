# FileForge

A fast, keyboard-driven file explorer for Windows, those who want an alternative to explorer.

**Download:** get `FileForge-Setup-2.3.0.exe` from the [latest release](../../releases/latest).

## Highlights
- Instant filename search across indexed folders (file contents are never read)
- W/A/S/D navigation, with smooth accelerating hold-to-scroll
- Quick access you can edit and drag folders into
- Preview panel, including real SolidWorks part thumbnails
- Tabs, drag files in and out (including from Outlook), undo for file operations
- Delete goes to the Recycle Bin by default

## Install
Windows 10/11 (64-bit). Run the Setup file. It installs for your user only and needs no
administrator rights. Settings and the search index live in `%LOCALAPPDATA%\FileForge`
and are kept when you uninstall.

The installer is not code-signed, so Windows SmartScreen may say "Windows protected your PC".
Choose **More info**, then **Run anyway**.
